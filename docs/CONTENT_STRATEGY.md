# Content Strategy — Laravel + SaaS Authority

## The thesis

Real growth comes from three forces working together:

1. **SEO traffic compounding** — articles rank, accumulate backlinks, and send leads for years
2. **Consistent content** — Google rewards sites that publish regularly in one topic
3. **Authority in one niche** — "Laravel + SaaS production systems," not generic dev blogging

## Your unfair advantage

| Others | You |
|--------|-----|
| Rewrite Laravel docs | Ship multi-tenant HRM, SaaS billing, payment gateways |
| Generic "top 10 tools" lists | Authentic tutorials from production debugging |
| Scatter across 10 topics | Own **Laravel + SaaS + Nepal payments** |

That combination is **monetizable**: freelance clients, remote contracts, course/community later, and micro-SaaS.

## Content mix (keep this ratio)

| Pillar | Share | Purpose | Examples |
|--------|-------|---------|----------|
| **SEO Tutorials** | 70% | Rank on Google, attract clients | Packages, multi-tenant, eSewa, deploy guides |
| **Developer Life** | 20% | Shares, backlinks, broader reach | Earn online, free tools, remote jobs |
| **Build Stories** | 10% | Trust, personal brand | "How I built…", journey posts |

Every viral or personal post should still **point back to Laravel/SaaS** when possible.

## Publishing cadence

| Frequency | Action |
|-----------|--------|
| **2× / month** | New SEO tutorial (1,500+ words, one target keyword) |
| **1× / month** | Build story or case study from real project |
| **1× / month** | Viral/list post for reach |
| **Weekly** | Update one old post (fresh `updated_at`, add section) |

Filament admin: `/admin` → Posts. Target one primary keyword per article in title, H1, first paragraph, and meta description.

## Monetization paths (in order)

1. **Inbound leads** — blog → contact form → Laravel API / SaaS projects
2. **Remote employment** — portfolio + blog as proof of seniority
3. **Productized services** — "Laravel SaaS MVP in 6 weeks," Nepal payment setup
4. **Micro-SaaS** — solve one problem you have already built for clients
5. **Later: course / community** — only after 50+ articles and email list

## Keyword clusters to dominate

Focus new content in these clusters (do not scatter):

- Laravel multi-tenant / SaaS architecture
- Laravel API + Sanctum production patterns
- Filament admin for SaaS backends
- **Laravel + Next.js** integration (App Router, SSR)
- **Headless / MDX blog** with server-side SEO
- **Cloudflare CDN** + Next.js / Laravel deploy
- Next.js image optimization with Laravel media API
- eSewa + Khalti + Laravel (Nepal-specific moat)
- Laravel deployment (Docker, DigitalOcean, CI/CD)
- Laravel packages and production checklist

This site (`frontend/docs/ARCHITECTURE.md`) is the live reference for the stack above — write tutorials from what you ship here.

## 90-day plan

### Month 1 — Foundation
- [ ] Submit sitemap to Google Search Console
- [ ] Enable Google Analytics
- [ ] Publish 2 tutorials from production experience
- [ ] Add internal links between related posts

### Month 2 — Compound
- [ ] Refresh top 3 posts with more detail + FAQ section
- [ ] One build story (case study with architecture diagram)
- [ ] Guest comment / answer on Laravel threads with blog links

### Month 3 — Monetize
- [ ] Clear "Work with me" CTA on top posts
- [ ] One lead magnet idea (e.g. "Laravel SaaS checklist PDF")
- [ ] Track Search Console queries → write posts for impressions you already get

## What not to do

- Chase AI hype topics unrelated to Laravel
- Publish without a target keyword
- Copy other blogs without production angle
- Abandon niche for generic "motivation" content

## Measuring success

| Metric | Tool | Target (6 months) |
|--------|------|-------------------|
| Organic clicks | Search Console | ↑ month over month |
| Ranking keywords | Search Console | 20+ in top 20 |
| Contact form / email | Analytics events | 2–5/month from blog |
| Avg. position (niche terms) | GSC | < 15 for long-tail |
